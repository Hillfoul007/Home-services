# How to Create Google Play Store Screenshots

## Quick Summary

**What you need:** 5-8 screenshots, 1080 × 1920 pixels, PNG/JPEG format

**3 Easy Methods:**

---

## METHOD 1: Direct Phone Screenshots (Easiest) ⭐ RECOMMENDED

### Step 1: Take Screenshots on Your Android Device
1. Open Laundrify app on your Android phone
2. Navigate to key screens:
   - Home/Hero screen
   - Service selection
   - Booking flow
   - Order tracking
   - Pricing page
3. Press: **Volume Down + Power Button** (hold 1-2 seconds)
4. Screenshot saved to: **Gallery → Screenshots**

### Step 2: Add Text Overlays with Canva (Free)
1. Go to **canva.com** (free version)
2. Search for "Phone screenshot" template
3. Upload your screenshot
4. Add text:
   - Size: 48-72pt (large, readable)
   - Color: White with dark shadow
   - Position: Top or bottom
   - Examples:
     - "Book Laundry in Seconds"
     - "Track Orders Live"
     - "Professional Quality Service"
     - "24-Hour Turnaround"

### Step 3: Download & Prepare
1. Download as PNG (1080 × 1920)
2. Crop to phone screen size if needed
3. Repeat for 5-8 different screens

**Time:** ~30 minutes for all screenshots
**Cost:** Free

---

## METHOD 2: Use Android Studio Emulator (Advanced)

### Step 1: Install Android Studio Emulator
1. Open Android Studio
2. Go to: **Tools → Device Manager**
3. Create a virtual device (Pixel 6, Android 13+)
4. Launch the device

### Step 2: Install Your App
```bash
cd android
./gradlew.bat installDebug
```

### Step 3: Take Screenshots
1. Run app in emulator
2. Navigate to each screen
3. Right-click emulator → **Take Screenshot**
4. Save as PNG

**Time:** 45 minutes setup + 15 minutes screenshots
**Cost:** Free
**Quality:** Professional

---

## METHOD 3: Use Figma Mockup (Most Professional) ⭐ BEST QUALITY

### Free Option: Figma
1. Go to **figma.com** (free account)
2. Create new file
3. Import iPhone 14 frame (search "Phone mockup" in community)
4. Screenshots go inside the frame
5. Add text overlays with design tools
6. Export as PNG (1080 × 1920)

### Paid Option: AppMockUp
- Website: **appmockup.com**
- Drag-drop app screenshots into device frames
- Professional output
- Cost: ~$5-10

**Time:** 1-2 hours for professional look
**Cost:** Free (Figma) or $5-10
**Quality:** Professional grade

## Text Overlay Guidelines

### Font Settings (Canva/Figma):
- **Font:** Sans-serif (Helvetica, Arial, Roboto)
- **Size:** 48-72pt (main heading)
- **Size:** 32-40pt (subtitle)
- **Weight:** Bold for main text
- **Color:** White (most readable)
- **Shadow:** Dark shadow to stand out

### Text Positioning:
```
┌─────────────────────────┐
│                         │
│  [Top: Main Headline]   │  ← Best for hero screen
│                         │
│                         │
│   [App Content Area]    │
│                         │
│                         │
│                         │
│                         │
│  [Bottom: Subtitle]     │  ← Or put subtitle here
│                         │
└─────────────────────────┘
```

## File Format & Size Requirements

### Google Play Store Requirements:
- **Format:** PNG or JPEG
- **Orientation:** Portrait (vertical)
- **Dimensions:** 1080 × 1920 pixels (9:16 aspect ratio)
- **File Size:** Max 15 MB per screenshot
- **Color Space:** RGB

### To Check/Convert in Canva:
1. Design at 1080 × 1920
2. Export → PNG (highest quality)
3. Check file size (should be < 5MB)

### If Using Figma:
1. Set artboard to 1080 × 1920
2. Export → PNG (4x scale)
3. Download directly

## How to Use Screenshots in Play Console

1. Go to **Google Play Console**
2. Select your app
3. Go to **Store Listing → Screenshots** (or **Graphics**)
4. Click **Add Screenshots**
5. Upload in order (1-8)
6. Preview before submitting
7. Screenshots appear in order on store page

### Layout on Store Page:
```
┌─────────────────────────┐
│  Screenshot 1 (Hero)    │
├─────────────────────────┤
│  Screenshot 2 (Service) │
├─────────────────────────┤
│  Screenshot 3 (Booking) │
├─────────────────────────┤
│  Screenshot 4 (Track)   │
├─────────────────────────┤
│  Screenshot 5+ (More)   │
└─────────────────────────┘
```

Users can swipe left/right to see all screenshots.

## Pro Tips

✅ **DO:**
- Use real app screenshots (not mockups alone)
- Add clear, large text (readable on small screens)
- Show actual features/functionality
- Use brand colors in overlays
- Highlight unique features first
- Test on mobile device to confirm readability
- Use bright colors for visibility
- Show active states (selected, filled forms)

❌ **DON'T:**
- Use placeholder/fake data
- Add too much text (max 2-3 lines per screenshot)
- Use tiny fonts (hard to read)
- Make false claims in text
- Include personal info (phone numbers, emails)
- Use low-quality images
- Oversaturate colors
- Hide important UI elements

### Before Uploading:
- [ ] 5-8 screenshots collected
- [ ] All resized to 1080 × 1920
- [ ] Text overlays added and readable
- [ ] File format is PNG or JPEG
- [ ] File size under 15 MB each
- [ ] Screenshots show actual app (not designs)
- [ ] Text matches your app features
- [ ] No personal information visible
- [ ] No spelling/grammar errors
- [ ] All in correct order (hero first, features next)

### After Uploading:
- [ ] Preview in Play Console
- [ ] Check on mobile device (if possible)
- [ ] Confirm ordering and visibility
- [ ] No screenshots cut off or distorted
