## 5. Data Security

### 5.1 Security Measures
We implement industry-standard security practices:

- **Encryption:** Data transmitted over HTTPS/TLS encryption
- **Password Protection:** Passwords stored as hashed, salted values
- **Access Control:** Only authorized personnel access data
- **Regular Audits:** Security reviews and penetration testing
- **Data Backup:** Secure, encrypted backups
- **Firewalls:** Network protection against unauthorized access

### 5.2 Limitations
While we implement robust security measures, no system is 100% secure. We cannot guarantee absolute security of your information. Use strong passwords and be cautious about sharing personal details.
